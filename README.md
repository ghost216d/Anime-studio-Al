# Anime Studio AI

Mobile-first anime studio using open-weight AI models.

## First version

The app provides series planning, character profiles, scripts, storyboard prompts, and project backup. Qwen text generation requires a separately hosted backend; GitHub Pages cannot execute AI models.

## Deployment

Publish the static `index.html` using Settings → Pages → Deploy from branch → main / root.

Never put API keys in frontend code.
